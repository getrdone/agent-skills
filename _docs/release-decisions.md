All 36 existing managed skill families remain available; coding-workflow and awesome-design-md bring the catalog to 38. Recipes, styles, references, technical assets and source notices are retained. Duplicate cross-skill pointer files were removed and their callers address the owner directly. Remotion map variants are retained in the map skill. High-end recipes remain complete in the active component-recipes reference with contextual wording.

The Dynamic Symmetry grid collection is now resources/dynamic-symmetry-grids inside this repository. It is included in distribution; no old design-resource path is required to use it. The full Awesome Design collection is local. Source data libraries and external services remain data/tools, not alternate managed skill authorities.

Every pre-existing skill has a preserved baseline release and a revised current release. Prior CDSJ releases 2.0.0, 3.0.0, 3.0.1 and 3.1.0 are restored inside the new version tree for explicit selection; live 3.2.0 is the immediate baseline and 3.3.1 is current (3.3.0 is the initial V5 release). Historical workspace links are relocated into this repository. No archive is consulted during current skill execution.

No page redesign, deployment or SQLite migration occurred. Operational SQLite memory remains a future project to evaluate. Fresh runtime checks and publication evidence are recorded in the final release report.

Maintenance verification retained sealed V5 releases, then advanced CDSJ to 3.3.1 to repair the tool-catalog path and web-studio to 1.2.1 to remove an inherited selector and stale lane-limit wording.
