# End-matter examples

Use the compact pattern for a short, single-topic transcript. Use the section-aware pattern for a multi-topic follow-along edition or download.

References from the presentation appear without a usage label. Only material added during study development receives **Additional related source**, placed immediately after the Bible reference or documentary-source title.

## Verification reminder

The source list grows around the transcript; it never edits the transcript to match later research. A stronger primary source may be added as a separate entry. An unresolved source remains visible until it is found. Verification tiers belong in internal editorial records unless the user requests a research audit; the public companion uses clean titles, descriptions, and meaningful source links.
