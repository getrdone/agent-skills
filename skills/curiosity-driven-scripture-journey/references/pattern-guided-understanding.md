# Guided Understanding Patterns

Load this family when the learner needs a clear route, a bridge from familiar to new, a modeled method, manageable chunks, or optional depth. Evidence provenance lives in `learning-pattern-sources.md`.

## LP-GU-01 — Promise and Route Preview

**Learning job:** orient the learner before cognitive load rises.

**Use when:** a journey has several evidence steps, unfamiliar territory, or a meaningful time commitment.

**Avoid when:** the answer is one short paragraph; a route preview would be longer than the content.

**Learner flow:** sincere question → exact payoff → 3–5 plain route labels → first useful evidence. Add an honest time or effort estimate only when it helps.

**Scripture adaptation:** name what will be examined, not what the learner must conclude. Example: “This journey compares the symbol in Revelation 13 with its Old Testament background, then states what the evidence supports and what remains interpretive.”

**Agent output contract:** provide `core_question`, `promised_payoff`, `route_labels`, `first_evidence`, and any known boundary. The opening must begin paying off the promise immediately.

**Access and age:** keep route labels short and literal. A screen reader should encounter the same outline. For younger learners, use fewer stops; for adults, do not use schoolish “Lesson 1 of 6” language unless requested.

**Evidence anchors:** Coursera’s course pages preview outcomes, level, workload, modules, and assessment types; BBC Bitesize organizes content by level, subject, and exam specification.

## LP-GU-02 — Familiar Anchor to One New Idea

**Learning job:** activate useful prior knowledge and cross one conceptual gap at a time.

**Use when:** the learner likely recognizes a verse, phrase, lived concern, image, or question that can support the next distinction.

**Avoid when:** the “familiar” anchor is an unverified assumption about the learner’s beliefs, culture, or knowledge.

**Learner flow:** recognizable anchor → explicit connection → one new idea → one evidence moment → micro-payoff.

**Scripture adaptation:** begin with a familiar line or sincere concern, then point to one feature that changes the question. Example: start with “the mark of the beast,” then notice that Revelation also describes a seal before defining either symbol.

**Agent output contract:** name the anchor, the new idea, and the bridge sentence. If the bridge needs more than two unexplained concepts, split it.

**Access and age:** use “you may have noticed” or neutral phrasing instead of “everyone knows.” For a child or first-time reader, make the anchor concrete; for an experienced reader, it may be a known interpretive tension.

**Evidence anchors:** Khan Academy sequences skills from prerequisites toward harder work; the project learning map and plain-language rule supply the Scripture-specific adaptation.

## LP-GU-03 — Worked Example, Faded Guidance, Independent Try

**Learning job:** make an invisible reasoning process visible, then gradually transfer responsibility.

**Use when:** learners need to see how to compare context, trace a repeated phrase, evaluate a claim, or use a source trail.

**Avoid when:** there is no defensible method to model, or the example would quietly predetermine a disputed conclusion.

**Learner flow:** fully modeled example → second example with prompts and partial guidance → similar independent observation → explanatory feedback.

**Scripture adaptation:** model the difference between observation and interpretation. Example: show how speaker, audience, and surrounding paragraph are identified in one passage; guide those checks in a second; invite the learner to identify them in a third.

**Agent output contract:** include the worked reasoning, the features that fade, the independent prompt, and the feedback. Do not merely show an answer and call it an example.

**Access and age:** keep the reasoning in text even if animated. Reduce writing or motor demand for younger learners without removing the thinking. Offer a “show the next step” control rather than forcing public failure.

**Evidence anchors:** Khan Academy exposes step-by-step solutions and practice; CodeAI lessons move through skill building, practice, assessment opportunities, and reflection.

## LP-GU-04 — One-Idea Micro-Chunk

**Learning job:** keep working-memory demand manageable while distributing real progress.

**Use when:** content is dense, mobile-first, new to the audience, or contains several passages and terms.

**Avoid when:** splitting would sever a single argument or turn every sentence into an unnecessary screen.

**Learner flow:** purpose label → one idea → one evidence item or example → optional low-pressure action → one-sentence payoff → next distinct chunk.

**Scripture adaptation:** a chunk may establish context, inspect one phrase, compare one passage, or state one inference. It should not introduce three doctrines and two historical claims at once.

**Agent output contract:** each chunk must have one dominant purpose and add evidence, clarity, or payoff. Delete chunks that only repeat or decorate.

**Access and age:** use short paragraphs, descriptive headings, and consistent control placement. Younger learners may need shorter chunks; adults still need complete, dignified explanations.

**Evidence anchors:** Duolingo groups work into bite-sized lessons and smaller units; BBC Bitesize uses concise guides and quizzes; Coursera exposes short videos, readings, and assignments inside modules.

## LP-GU-05 — Learner-Controlled Detail

**Learning job:** preserve a clear core path while making depth available at the moment it becomes useful.

**Use when:** original-language notes, historical background, translation comparisons, source records, or interpretive qualifications would overload the main explanation.

**Avoid when:** the detail is necessary to understand or verify the primary claim. Essential evidence never belongs behind an optional reveal.

**Learner flow:** complete core statement → clearly labeled optional detail → learner opens it if needed → detail returns to the main question.

**Scripture adaptation:** use optional panels for a lexical range, manuscript note, historical source, full bibliography, or additional translations. Keep the selected passage, main evidence, answer, and limits in the core document.

**Agent output contract:** label every reveal by content, not “More.” State why it matters in the first line. Provide a return sentence that connects the detail to the main reasoning.

**Access and age:** use semantic headings or `<details><summary>` with keyboard support and sensible focus. Ensure print, no-JavaScript, and screen-reader views contain the detail. Avoid nested disclosure chains.

**Evidence anchors:** CK-12 integrates core text, simulations, practice, related modalities, highlights, and settings without forcing every resource into one reading stream; BBC Bitesize uses concise guide layers and optional media or practice.
