## One-sentence idea

**Dynamic symmetry** = pick a lawful rectangle for your crop, then use an **armature** (diagonals + reciprocals + eyes) so placement has unity, rhythm, and movement—not random rule-of-thirds habit.

**Soft standard:** use it for layout, spacing, hierarchy, thumbs, and heroes unless there is a reason not to.

---

## Core definitions

| Term | Definition | Why it matters |
|------|------------|----------------|
| **Dynamic symmetry (DS)** | Composition system (Hambidge / Glover): related lines inside a rectangle for life, order, variety. | Better default than thirds-only. |
| **Armature** | Construction lines in the frame (diagonals, reciprocals, H/V through eyes, optional MAD). | Map for subjects and type. |
| **Root rectangle** | Rectangles grown from a **square** by swinging diagonals: √2, √3, √4… | Matches common crops (root 3 ≈ 16:9). |
| **Phi (φ)** | Ratio ≈ **1.618**; “whirling squares.” | Natural/organic proportion. |
| **Root-phi** | Ratio ≈ **1.272**. | Near 11×14 / letter family. |
| **1.5 rectangle** | Square + half; ratio **1.5**. | 4×6 / 2:3 stills. |
| **Mother rectangle** | Outer canvas you design in. | All subdivisions live inside it. |
| **Basic armature** | 2 main diagonals + 4 reciprocals + optional H/V through eyes. | Enough for most work. |
| **Diagonal** | Corner-to-corner line. | Primary energy / subject alignment. |
| **Baroque / sinister diagonal** | Names for the two main diagonals. | Say which one carries the subject. |
| **Reciprocal** | Line from a corner meeting a diagonal at **90°**; cuts a smaller related rectangle. | Related margins and secondary zones. |
| **Eye** | Intersection of armature lines. | Focal seats; spawn new lines. |
| **Polar point** | Eye where reciprocal meets diagonal at 90°. | Hinge for H/V of basic armature. |
| **Theme** | Subdivision of the mother into related areas (Hambidge). | Rhythm / modules. |
| **Theme of 2/3/4/8…** | Equal related modules (often vertical). | Panels, sections, multi-beat layouts. |
| **NDT** | Numeric dynamic theme — equal divisions from the basic armature. | Easy “how many modules” language. |
| **MAD** | Major area divisions — shrink basic armature into main sub-areas. | Multi-zone hierarchy in one frame. |
| **Overlapping roots** | Slide roots along eye increments for a lawful custom outer size. | Custom canvases without sloppy grids. |
| **Compound roots** | More than one root system in one design. | Complex multi-zone work. |
| **Whirling squares** | Phi spiral of proportional squares. | Phi-family grids. |
| **Gamut / echo** | Repeat an angle/diagonal so shapes rhyme. | Unity without cloning. |
| **Crop integrity** | Final crop ratio must match the rectangle you composed for. | Changing ratio after compose breaks DS. |
| **Rule of thirds (ROT)** | Generic 3×3; predictable. | DS allows more variety on purpose. |
| **Better-than-thirds variety** | Vary diagonal, theme, horizon, negative space across pieces. | Anti-repetition with structure. |
| **Breathing room / gaze direction** | Space in front of gaze; mass vs empty. | Comfort + balance on strong lines. |
| **Diagonal gauge** | Tool image to discover which diagonal family a frame fits. | Analysis before picking a PNG. |

## Basic armature (30 seconds)

1. Both main diagonals  
2. Reciprocals (90° to diagonal)  
3. Eyes  
4. Optional H/V through eyes  
5. Hero on line/eye; support on echoes  
6. Empty space is a shape  

Most thumbs/heroes stop here. **MAD** if multi-zone; **themes** if modular sections; **overlap** if custom outer size.
