# Active Discovery Patterns

Load this family when the learner can inspect, compare, arrange, manipulate, or transfer evidence instead of only receiving an explanation. Evidence provenance lives in `learning-pattern-sources.md`.

## LP-AD-01 — Predict, Inspect, Revise, Explain

**Learning job:** turn passive reading into an evidence-led change of mind or refinement of understanding.

**Use when:** a passage, relationship, sequence, or contextual change can produce an observable result.

**Avoid when:** the prompt would pressure the learner to declare a belief, reveal sensitive information, or guess a doctrine before seeing the evidence.

**Learner flow:** low-stakes prediction → inspect the text or model → state what changed or stayed → revise the prediction → receive or form an explanation.

**Scripture adaptation:** ask an observational question such as “Which image appears first?” or “What changes when the surrounding verses are included?” Let the learner revise without penalty.

**Agent output contract:** provide the prediction prompt, the inspectable evidence, the revision opportunity, and the explanatory payoff. A prediction without later resolution is a broken pattern.

**Access and age:** never require drag, handwriting, or timed speech. Offer tap, keyboard, and plain-text response paths. A private “think first” pause can replace input collection.

**Evidence anchors:** PhET’s active-learning guidance explicitly uses predictions, observations, explanations, and mental-model revision; Duolingo teaches through early interaction and pattern noticing.

## LP-AD-02 — Direct Manipulation, Visible Consequence

**Learning job:** make an abstract relationship concrete by letting one meaningful variable change.

**Use when:** context window, translation, chronology, speaker, evidence category, map location, or another dimension changes what the learner can observe.

**Avoid when:** the control changes only decoration, implies certainty the evidence does not support, or requires several variables to move at once.

**Learner flow:** orient to the current state → change one variable → see and read the consequence immediately → reset or compare → name the relationship.

**Scripture adaptation:** useful controls include expand surrounding context, toggle an approved translation, move along a dated timeline, focus repeated terms, or filter claims by text/interpretation/application.

**Agent output contract:** define the controlled variable, the visible consequence, the explanatory text, the reset state, and the non-interactive equivalent. The interaction must answer a learning question.

**Access and age:** expose current state in text, not color alone. Support keyboard, touch, zoom, and reduced motor precision. Preserve the same evidence in the document source.

**Evidence anchors:** PhET simulations let learners change experiment settings and observe dynamic representations; Brilliant centers visual, interactive problem solving.

## LP-AD-03 — Compare, Notice, Name the Difference

**Learning job:** focus attention on a material similarity or difference before explaining its significance.

**Use when:** comparing passages, approved translations, speakers, genres, historical claims, interpretations, or before/after context.

**Avoid when:** the comparison cherry-picks wording, treats English variation as automatic proof, or places unlike things side by side without explaining the limits.

**Learner flow:** orient to the two items → prompt one feature to notice → learner inspects → reveal or confirm the difference → explain why it matters and what it does not establish.

**Scripture adaptation:** keep translation names and verse boundaries visible. Compare the underlying term and context when the wording difference bears doctrinal weight.

**Agent output contract:** include the comparison target, noticing prompt, named difference, significance, limit, and citations. Never stop at highlighting.

**Access and age:** provide a stacked mobile view and a semantic table or list. Do not encode the comparison only with color, animation, or spatial position.

**Evidence anchors:** Brilliant uses visual comparison and step-by-step interaction; CK-12 mixes text, diagrams, interactives, and concept maps; the Scripture translation-review contract supplies the integrity boundary.

## LP-AD-04 — Sort, Sequence, Map Evidence

**Learning job:** reveal structure, chronology, category, or relationship by arranging evidence.

**Use when:** order matters—events, speakers, claims, literary structure, cause/effect, covenant setting, or source authority.

**Avoid when:** several orders are defensible and the interface silently treats one interpretation as factual, or when arrangement adds no insight.

**Learner flow:** inspect items → arrange or classify → see immediate structural feedback → compare with the evidence-supported arrangement → explain one consequential relationship.

**Scripture adaptation:** sequence dated events; map who speaks to whom; sort statements into text, interpretation, application, and uncertainty; connect repeated phrases across passages.

**Agent output contract:** specify the rule for placement, any acceptable alternatives, the explanation after placement, and a fully readable solution. Do not use the activity to unlock the answer.

**Access and age:** provide move-up/down buttons or select controls in addition to drag. Use ordered lists and text labels. Allow large targets and untimed completion.

**Evidence anchors:** CodeAI commonly progresses through level sequences, check-for-understanding steps, builds, and reflections; CK-12 concept maps expose linked concepts; PhET uses multiple dynamic representations.

## LP-AD-05 — Case, Principle, Transfer

**Learning job:** help the learner abstract a principle from concrete evidence and test it in a fresh context.

**Use when:** the journey has a genuine second case that can reveal whether the learner understood the reasoning rather than memorized a phrase.

**Avoid when:** the second case depends on speculative typology, ignores genre or covenant differences, or is too distant for a fair transfer.

**Learner flow:** inspect one concrete case → name the supported principle → apply it to a new but related case → compare reasoning → state limits.

**Scripture adaptation:** after modeling how immediate context identifies a symbol’s function in one passage, invite the same contextual checks in another passage. Do not assume the symbols mean the same thing.

**Agent output contract:** identify the invariant principle, the changed features in the transfer case, the prompt, the feedback, and the boundary against overgeneralization.

**Access and age:** keep the transfer case short enough that reading demand does not obscure the reasoning. Offer oral reflection, text entry, or a private pause as equivalent options.

**Evidence anchors:** Coursera modules frequently move from concepts to hands-on assignments or capstones; CodeAI moves from skill building to mini-projects and reflection; Brilliant emphasizes applied problem solving.
