# Feedback and Mastery Patterns

Load this family when the learner needs explanation after an action, help on demand, a dignified recovery path, later retrieval, or prerequisite repair. Evidence provenance lives in `learning-pattern-sources.md`.

## LP-FM-01 — Immediate Explanatory Feedback

**Learning job:** convert an action or answer into understanding while the learner still remembers the reasoning.

**Use when:** the learner predicts, compares, sorts, retrieves, or makes an observable choice.

**Avoid when:** there is no meaningful response to explain, or instant feedback would interrupt a reflection that benefits from time.

**Learner flow:** response → specific acknowledgment → correct or refine → explain why from the evidence → one useful next action.

**Scripture adaptation:** feedback may say, “You noticed that the seal appears on the forehead. The text connects that image to allegiance; it does not yet establish every later interpretation.”

**Agent output contract:** feedback must address the actual response category, cite or point back to evidence, and state a boundary when needed. “Correct,” “wrong,” red/green, or confetti alone does not count.

**Access and age:** announce feedback to assistive technology without stealing focus. Use calm language, icons plus text, and no shame. For a private pause, place feedback immediately after the prompt.

**Evidence anchors:** Brilliant provides instant custom feedback; Duolingo’s Explain My Answer gives in-lesson explanations tied to the learner’s error; CK-12 practice shows immediate feedback.

## LP-FM-02 — Hint Ladder

**Learning job:** provide the smallest useful help while preserving thought and agency.

**Use when:** a learner can get stuck locating evidence, distinguishing categories, or making the next reasoning step.

**Avoid when:** the learner needs prerequisite instruction rather than a hint, or the answer is sensitive and should simply be stated.

**Learner flow:** try or pause → request help → progressively stronger hint → resume the same task → full explanation remains available.

**Default ladder:** restate the goal → point to the relevant passage or feature → name the distinction to inspect → model the first reasoning step → show the complete worked explanation.

**Scripture adaptation:** a hint may direct attention to speaker, audience, repeated wording, immediate context, genre, or date. It must not smuggle in an unsupported interpretation.

**Agent output contract:** write at least three graduated levels plus the complete explanation. Hints must be learner-controlled and carry no score or spiritual penalty.

**Access and age:** controls say what they reveal—“Point me to the verse,” not only “Hint.” Preserve opened hints for keyboard and screen-reader users. Younger learners may use fewer, more concrete levels.

**Evidence anchors:** Khan Academy exposes solution steps one at a time; Brilliant’s tutor guides thinking without simply supplying the answer; CK-12 practice includes hints and recommended resources.

## LP-FM-03 — Safe Mistake, Recovery Try

**Learning job:** turn an incomplete or mistaken attempt into a new opportunity without threat.

**Use when:** an activity has common misconceptions or partial observations that can be diagnosed.

**Avoid when:** the task concerns personal belief, moral worth, trauma, or another area where “mistake” framing would be inappropriate.

**Learner flow:** attempt → kind, specific feedback → isolate one missing feature → near-transfer retry → acknowledge improved reasoning → continue.

**Scripture adaptation:** if a learner selects a verse that uses the same word but not the same context, explain the contextual mismatch and offer a second comparison. Do not reduce theology to a right-answer game.

**Agent output contract:** define likely response categories, feedback for each, and a retry that changes surface details while preserving the learning target.

**Access and age:** retries are untimed and do not erase progress. Do not use streak loss, hearts, public rankings, or punitive sound. Permit “show me” at any point.

**Evidence anchors:** CodeAI lets teachers return work to “Keep Working” and supports iterative project improvement; Brilliant and Duolingo provide guidance tied to where the learner is stuck.

## LP-FM-04 — Retrieval, Spaced Return

**Learning job:** make a meaningful idea retrievable after attention has moved elsewhere.

**Use when:** a reference, distinction, reasoning move, or central answer will matter later in the same journey or a future one.

**Avoid when:** the prompt tests trivia, exact wording that was never a goal, or belief rather than understanding.

**Learner flow:** meaningful first exposure → short retrieval after a delay → explanatory feedback → later return in a different form or context → synthesis.

**Scripture adaptation:** retrieve the function of a symbol, the identity of a speaker, a cross-reference relationship, or the difference between text and interpretation. Allow reference lookup when memorization is not the goal.

**Agent output contract:** state what must remain retrievable, the first prompt, the spacing point, the varied return prompt, and feedback. Do not repeat the same multiple-choice item verbatim.

**Access and age:** accept recognition, recall, ordering, or explanation based on the actual goal. Avoid timers. Give a “review first” route for learners with memory or language barriers.

**Evidence anchors:** Duolingo builds spaced and mixed review into its path; Khan Academy Mastery Challenges revisit prior skills across a course.

## LP-FM-05 — Adaptive Remediation, Next Best Step

**Learning job:** repair a missing prerequisite without derailing or humiliating the learner.

**Use when:** an observable response shows that a small earlier concept blocks the current evidence path.

**Avoid when:** adaptation would infer sensitive traits, silently lower expectations, or place essential truth on a personalized branch that others cannot access.

**Learner flow:** detect a specific gap → offer a short optional repair → explain or practice that prerequisite → confirm readiness → return to the original point.

**Scripture adaptation:** if speaker/audience is unclear, offer a two-minute context refresher before resuming the interpretation. If translation differences confuse the learner, explain the relevant term and return.

**Agent output contract:** define the trigger, repair content, maximum detour, return point, and skip option. Base adaptation on the current response, not a fixed learner label.

**Access and age:** the repair is available to everyone and can be opened directly. Keep language dignified: “Review the context” rather than “Beginner help.”

**Evidence anchors:** CK-12 practice adjusts difficulty and recommends readings or videos when a learner struggles; Brilliant and Khan Academy personalize practice around progress and gaps.
