## What it is (plain English)

**Dynamic symmetry** is a way to build an **armature** (a set of meaningful lines) inside a rectangle so placement has **unity, rhythm, and movement**—not random “rule of thirds” habit.

Think of it like **grammar for the frame**:

- The rectangle shape is chosen to fit the subject (not the other way around).
- Inside that rectangle you draw **diagonals**, **reciprocals**, and lines through **eyes** (intersections).
- Important things land on those lines and crossings—or deliberately avoid the boring “thirds” zones to stay creative.
- You can subdivide further (**themes**, **MAD**, overlaps) when the design needs finer rhythm.

Jay Hambidge: design in rectangles without dynamic symmetry tends to feel “flat and dead.” The point is **life and growth** in the composition—not magic corners.

## Why use it (including for ministry / web / YouTube)

| Need | How DS helps |
|------|----------------|
| Visual hierarchy | Eyes and major lines tell you where the dominant subject and secondary beats belong |
| Spacing & margins | Reciprocals and major divisions create *related* empty space, not arbitrary padding |
| Thumbnails | One clear figure-ground hit aligned to a strong diagonal/vertical beats “center + clutter” |
| Web sections | Same armature across a hero crop, type block, and supporting image keeps the page calm and ordered |
| Variety without chaos | Different **themes** and diagonals keep episodes from looking identical while staying related |
| Better than ROT alone | Rule of thirds is predictable; DS gives many lawful options so work doesn’t all look the same |

**Soft standard:** For any layout, crop, spacing, or hierarchy task, **default to choosing a rectangle + armature** (or loading a matching PNG grid from the pack). Skip only when the user forbids grids or the task is pure copy with no visual layout.

## Core vocabulary

**Full skim glossary (preferred):** [`glossary.md`](glossary.md).

| Term | Meaning |
|------|---------|
| **Root rectangle** | Family of rectangles grown from a square by swinging diagonals (√2, √3, √4, √5, …) |
| **Phi (φ) rectangle** | ≈ 1.618 — “whirling squares”; related to natural proportion |
| **Root-phi** | ≈ 1.272 — near common print sizes (e.g. ~11×14 family) |
| **1.5 rectangle** | Square + half; classic 2:3 / 4×6 / 24×36 family |
| **Basic armature** | 2 main diagonals + 4 reciprocals + H/V lines through the **eyes** |
| **Eye** | Intersection where lines meet — place focal points or generate new lines |
| **Polar point** | Special eye where reciprocal meets major diagonal at 90°; generates H/V of the basic armature |
| **Baroque / sinister diagonal** | The two main corner-to-corner diagonals (terminology for communication) |
| **Reciprocal** | Line from a corner meeting a diagonal at 90°; carves smaller related rectangles |
| **Theme** | How the mother rectangle is subdivided into smaller related areas (Hambidge) |
| **NDT / numeric dynamic theme** | Equal vertical (etc.) divisions into smaller root rectangles inside the mother |
| **MAD (major area divisions)** | Shrink the basic armature into the main sub-areas (often ~theme of two) for finer control |
| **Overlapping roots** | Sliding root rectangles along eye increments to build compound canvases with equal root counts |
| **Compound roots** | Combining root systems for complex multi-zone layouts |
| **Crop integrity** | Final crop must match the rectangle you composed in—or the armature breaks |
| **Better-than-thirds variety** | Vary diagonal, theme, horizon, and negative space so pieces do not all look like ROT |

## Root ratios (choose canvas to fit the subject)

Build roots from a square: swing the diagonal of the square → root 2; swing that diagonal → root 3; and so on.

| Rectangle | Ratio (long/short) | Common cousins |
|-----------|--------------------|----------------|
| Root 2 | ≈ 1.414 | Near 5×7 |
| Root 3 | ≈ 1.732 | Near **16:9** cinema / YouTube landscape |
| Root 4 | 2.0 exactly | Double square |
| Root 5 | ≈ 2.236 | Near ultra-wide / 21:9 family |
| Root 6 | ≈ 2.449 | Cinematic / wide graphic |
| Root 7 | ≈ 2.646 | Very wide / panorama |
| Phi | ≈ 1.618 | Near 1.5; whirling squares |
| Root-phi | ≈ 1.272 | Near 11×14, letter-ish |
| 1.5 | 1.5 | 4×6, 8×12, 24×36 stills |

**Rule:** Know the subject structure first → pick the rectangle that *hosts* it. Do not force a subject into a random 16:9 if a stacked/root-phi portrait armature is truer—unless the delivery platform forces the crop (then compose *for that crop* with a matching grid).

**Crop integrity:** Cropping after compose to a *different* ratio breaks the armature. Match final delivery ratio when you choose the grid.

Sizing example: keep length 36″, want root 3 → short side ≈ 36 / 1.732 ≈ 20.78″.

## Basic armature (always start here)

1. Draw both main **diagonals** (corner to corner).  
2. From corners, drop **reciprocals** that meet a diagonal at 90°.  
3. Mark **eyes** (intersections).  
4. Optionally add **horizontals and verticals through eyes**.  
5. Place dominant subject on a strong line/eye; echo with secondary elements on related lines (gamut / echoes).  
6. Use **negative space** as an active shape, not leftover.

That’s enough for most thumbnails, heroes, and section layouts.

## MAD, themes, overlaps (when to go deeper)

| Tool | Use when |
|------|----------|
| **MAD** | Multiple zones (title + face + prop); need hierarchy inside the same frame |
| **Theme of 2 / 3 / 4 / 8…** | Repeated modules, comic/panel rhythm, multi-beat page sections |
| **Overlapping roots** | Custom canvas that must stay “lawful” for fine-art or multi-figure design |
| **Phi / Ghyka-inspired packs** | Organic, human, nature-led pieces; still no nude study imagery |

Photographers often stay at basic armature + MAD; illustrators/UI may use deeper themes.

---

## Avoiding sameness (better than rule of thirds)

Rule of thirds parks everything on the same intersections. Dynamic symmetry still *allows* those zones, but master practice **varies**:

- Different diagonals, high/low horizon, extreme negative space, close-ups  
- Different root themes so episode art doesn’t clone itself  
- “Brownie points” for not defaulting every subject to the same thirds hotspots  

Always keep **balance**, **gaze direction**, and **breathing room**.

### Workflow for any visual task

1. **Platform crop** — 16:9, 1:1, 9:16, 4:5, page width, etc.  
2. **Pick nearest root / phi / 1.5** (e.g. 16:9 ≈ root 3).  
3. **Load a matching PNG** from US or A4, H or V, as an overlay reference (or mentally reconstruct basic armature).  
4. **Place** subject, type, and supporting elements on diagonals/eyes/MAD.  
5. **Grayscale hierarchy** check, then palette.  
6. **Document** in visual direction: which rectangle + which grid file (filename).  
7. Never pull figure studies from the non-safe PDFs into outputs.

### Diagonal gauges

Use `Diagonal Gauge*.jpg` when analyzing an existing frame of unknown ratio—find the diagonal family before choosing an overlay.
