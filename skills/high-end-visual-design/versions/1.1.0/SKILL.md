# High-end visual design

Assess coherence, typography, spacing, surfaces, component craft and motion against the project design specification. Use [component and motion recipes](references/component-recipes.md) for the complete aesthetic options, detailed values, responsive variants, performance guidance and review checklist.

Select treatments that serve this audience and content. Fonts, layouts, depth treatments, glass, button shapes and animation counts have no universal bans or mandates. Keep accessible static states and reduced-motion behavior. Do not assume paid fonts are available. Preserve real content and working interactions. Coordinate implementation through web-studio.
