# Deliverable — polish

```text
WEB-STUDIO: 1.1
HTML-DELIVERABLE: polish
EDIT: <one named change>
```

One unit of work. Show the diff. Wait.

## Unit

One user-named change. Examples — the Hebrews citation; wire the transcript button; swap `speaker.jpg`; contrast on the legal line.

If the user lists five items, do item 1 only, then ask.

## Method

1. Read `DELIVERABLE.md` for stack and surface.
2. If the change is copy, consult `references/voice.md` and the calling skill’s brief. Do not invent a campaign voice.
3. If the change is a control, consult `references/interaction.md`. Do not add a new interaction system.
4. If the change is a picture, replace one named slot. Do not regenerate the set (use images phase for a full art pass).
5. If the change moves layout regions or focal imagery, load `skills/dynamic-symmetry/SKILL.md` and check against the recorded armature (or choose one if missing) before editing.
6. For anti-slop / premium-feel critiques only, consult `skills/design-taste-frontend/SKILL.md` or `skills/high-end-visual-design/SKILL.md` — do not open a redesign campaign unless asked.
7. Edit only the target file or selector.
8. Stop.
