# Interaction (consult only)

This is not a lane.

Clone places real controls (button, form fields, share). Theme does not add JS. Polish wires one control.

Defaults:

- Play control is a button or video element, not a picture of a triangle.
- Forms have labels, names, and a visible submit.
- Keyboard focus visible. `prefers-reduced-motion` respected.
- No new carousel / modal / tab system unless the source already has it and polish is asked to fix that one control.
