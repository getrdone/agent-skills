# Image slots

Named paths. Generate at clone if empty. Later change = polish, one file.

Typical Final Days hero:

| Slot | Path | Content |
|---|---|
| flag | `flag.jpg` (or `public/flag.jpg`) | Flag fading to paper |
| capitol | `capitol.jpg` | Capitol in pale sky |
| speaker | `speaker.jpg` | Studio portrait for the video frame |
| hills | `hills.jpg` | Landscape under the essay |

Do not bake logo, side copy, play, or script title into a photo.
Do not treat mockup crops as policy.
