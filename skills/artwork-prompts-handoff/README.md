# artwork-prompts-handoff

Default path for artwork when API credits (Canva / Leonardo / etc.) are not in play:

1. Agent writes `prompts/artwork-prompts_<agent>.md` (versioned `_vN` on re-run) with every paste-ready prompt; promote to bare `artwork-prompts.md` only when the user chooses the final pack.  
2. Human generates assets one by one in their own tools.  
3. Files land in `mood/` or `deliverables/assets/`.  
4. Agent continues layout with real files.

Entry: `SKILL.md`
