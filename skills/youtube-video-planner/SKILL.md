# YouTube Video Planner (Before You Hit Record)

Growth is decided before recording: **the idea sets the ceiling, the execution determines the result.** Your job with this skill is to move the user through five stages and hand them a **video brief** — a validated idea plus packaging — before they invest time filming.

**Standing rules (aligned with curiosity-driven-scripture-journey):**
- Output to the user stays lean. Content written for the public reader is expanded, interesting, and conversational (still never using “we/us/our” as if sitting beside the reader).
- Descriptions and pre-click copy must leave an additional open curiosity gap and support dual-audience design (early CTA + continued tension). Vary structure deliberately.
- Every generated file identifies the creating agent.

## ⭐ ALWAYS end with the Packaging Report — and it runs in TWO phases

**Every time this skill runs, the response MUST end with the Packaging Report.** It is delivered in **two phases**, and you do NOT skip ahead:

- **Phase 1 — Titles (always first).** Evaluate **every** title category, generate **4 or 5 titles per category**, mark the **single category that best fits** this video/idea/transcript, then **STOP and ASK the user which category (or which specific titles) to build thumbnail concepts from.** Do not generate thumbnails yet.
- **Phase 2 — Thumbnails (only after the user answers).** Using the category/titles the user picked, give the thumbnail **rule in play** + **3–4 concepts**.

This applies whether the user asked for the full five-stage brief, "just titles," or "package this video." The only time you go straight to Phase 2 is when the user has *already* told you which titles/category to use. Never dump thumbnails in the same turn as the title report unless the selection is already known.

## How to run it

1. Ask what the user has so far: a raw topic, a rough idea, a finished/released video, or just a channel/goal. Ask for their **view goal** and their **model channels** if they know them. Don't over-interrogate — one short round, then work. If a transcript or finished video is provided, skip ideation and go straight to packaging.
2. Walk the stages that apply, **in order**. Each stage has a gate. Use `references/framework.md` for the full method and `references/checklists.md` for the rules, formulas, categories, and thumbnail formats.
3. End with the **Packaging Report**. If the user wanted the full pre-record brief too, produce the Video Brief first, then the Packaging Report.

## The five stages (gates in **bold**)

1. **Ideation** — Generate with **Topic × Format × Angle**; filter on **TAM** (validate via *outliers* — videos that beat their own channel's average — vs. the user's view goal) and **Remarkability** (novel enough to be remarked upon). *Gate: idea clears both, expressed as a rough working title.*
2. **Title** — Generate **30+** variations (head → model-channel format extraction → outlier power-words → expansion seeded with the user's list). Enforce title rules. *Gate: ≥3 titles each with one strong curiosity gap, ready to AB test.*
3. **Click trigger** — Cast titles as **desire, fear, or curiosity** and check audience size. *Gate: trigger matches the user's goal (broad reach vs. narrow/qualified).*
4. **Thumbnail** — List content elements → pick a format (result / before-after / novelty / comparison) that matches the curiosity gap → **tease, never reveal**. *Gate: a concept the viewer can't "solve" from the thumbnail alone.*
5. **Story & retention** — Define **Promise → Progress → Payoff**; set **Constant + Variable + Tension + Payoff** for repeatable formats; make the subject (not the creator) the protagonist. *Gate: ≥1 clear payoff and a reason-why to "land the plane."*

## Key rules to never skip

- **Idea ≠ packaging.** The idea is the inside of the video; the title+thumbnail is the outside.
- **You can't judge your own idea from inside the jar** — reach for external signal, not gut feel.
- **One strong curiosity gap** per title; if you have to guess the question it raises, it's too weak.
- **Tease, don't reveal** in the thumbnail.
- **Truth over clickbait.** Every promise in the packaging must be paid off by the video. Flag any title/thumbnail the content can't deliver.
- **Match the brand's tone.** For sensitive, faith, kids, or institutional content, offer a reverent/safe variant alongside any punchy one.

# 📋 THE PACKAGING REPORT (required output format)

## PHASE 1 — Titles by category (always produced first)

Evaluate **every** category below — do not skip any. If a category is a genuinely poor fit for this video, still generate its 4 or 5 titles and add a one-line note that it's a weak angle here (don't silently drop it). Generate **4 or 5 titles per category**. Keep every title skimmable (aim <65 characters), most important words upper-left, ~5th-grade reading level, **one** clear curiosity gap. Match brand tone; offer a reverent/safe variant for sensitive content.

### Core categories (always evaluate — map to the three click triggers)

- **🔍 Curiosity** — opens an information gap; the viewer must click to close it.
- **😱 Fear / Loss** — a risk to avoid, a mistake, or a warning.
- **✨ Desire / Hope** — an outcome or transformation they want.
- **🔎 Search-friendly / SEO** — keyword-forward, phrased how people actually search.
- **🪞 Relatability / Identity** — speaks to who the viewer already is ("if you're a…").
- **🏆 Authority / Proof** — numbers, named results, credibility, receipts.
- **⚡ Contrarian / Novelty** — myth-busting, "nobody tells you," the surprising angle.

### Strong additional categories (evaluate when they clearly fit)

Add these when the video naturally supports them. Give each its own 4–5 titles.

- **⏰ Urgency / Timely** — creates pressure with a time element, current event, deadline, or “now vs later.” Use when the topic has a natural clock or recent trigger that raises stakes.
- **❤️ Story / Emotional** — leans on personal narrative, transformation story, or emotional stakes. Use when a human story or felt impact opens a stronger gap than pure information.
- **❓ Question** — poses a direct question the viewer wants answered. Use when a clean question form creates a tighter open loop than a statement title.
- **🛡️ Warning / Protection** — highlights a risk, common trap, deception, or way to stay safe. Use when the core value is avoiding a specific mistake or threat.
- **📜 Pattern / Fulfillment** — shows that something predicted, claimed, or written is now visible or happening. Use for “this was said… and here is the evidence” angles.
- **🌱 Growth / Next Step** — focuses on practical change, improvement, or how to actually live it out. Use when the video ends with an actionable takeaway or identity shift.
- **🔄 Comparison / Contrast** — sets two views, methods, or outcomes against each other. Use when the strongest curiosity comes from “A vs B” or “what most people think vs what works.”

### Situational / secondary (add only if they clearly strengthen the packaging)

- **👥 Community / Belonging** — speaks to “people like us” or a shared identity group. Overlaps with Relatability; use when group identity is the primary pull.
- **📖 Source Spotlight** — centers a specific document, quote, data set, primary source, or key text as the curiosity driver.
- **🔥 Challenge / Call** — soft invitation or challenge to act or decide. Use sparingly and keep tone brand-appropriate.

The core seven remain non-negotiable because they map directly to the three proven click triggers (Curiosity / Fear / Desire). The additional categories expand reach and precision without diluting the core.

Then:
- **➡ Best-fit category:** name the single category you'd bet on for this video + one sentence why (tie it to the audience and the goal).
- **Browse vs search:** one line on which to lead with and why.
- **Top 3–5 to A/B test:** list them as (title | category | gap), including a control near any existing title if one exists.

**End Phase 1 by asking the user:**  
*"Which category — or which specific titles — should I build thumbnail concepts from?"*  
Then stop and wait. Do not produce thumbnails in this turn.

## PHASE 2 — Thumbnail (only after the user picks)

Build concepts from the category/titles the user selected.

- **Rule in play:** name the governing principle (usually **"tease, don't reveal"**, but could be *"one focal point,"* *"emotion on the face,"* *"contrast/transformation,"* *"big readable text ≤4 words,"* or *"show the result"*). One sentence on why it applies here.
- **3–4 concepts**, each as: **Concept X — Name (format: result / before-after / novelty / comparison):** visual description; overlay text (≤4 words, upper-left, don't repeat the title); **the tease** (what it withholds so the click is earned). Mark the one you'd run first.
- If tone is sensitive, add a one-line note on keeping it respectful/accurate.

## Video Brief template (for pre-record planning, before the Packaging Report)

```
# Video Brief — <working title>

## Idea
- Topic / Format / Angle:
- TAM / proof: <outliers found, their view range vs. view goal>
- Remarkability: <what makes it novel>
- Verdict: greenlight / tweak / kill — why

## Story & retention
- Promise / Progress / Payoff:
- Protagonist: <the subject, not the creator>
- Format ingredients: Constant / Variable / Tension / Payoff
- "Land the plane" line:
```

See `references/framework.md` for the full reasoning behind each stage and `references/checklists.md` for the copy-ready formulas, title categories, click triggers, and thumbnail formats.
